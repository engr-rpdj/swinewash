        Download Results for MATLAB

        swinewash_validate.mOne file to run in MATLAB. Holds every input and result, recomputes them independently, prints deterministic and Monte Carlo PASS or FAIL tables with a validation score, and writes matlab_results.csv.
        swinewash_summary.csvEvery input, the 10 KPIs and every metric, one per row, with units, type and tolerance.
        swinewash_hydraulics.csvPer branch: fittings, elevation, loss breakdown, Reynolds number, friction factor, K, nozzle PSI, flow, exit speed.
        swinewash_coverage.csvCoverage percent per branch and surface, with each branch's share.
        swinewash_cleaning_curve.csvPercent cleaned, remaining, rate and cumulative water every 5 seconds.
        swinewash_floor_grids.csv40 by 32 floor cells: position, spray hits, starting dirt.
        swinewash_results.jsonMaster exchange file: inputs, KPIs, losses, coverage, cleaning, water and energy in one structured file (jsondecode in MATLAB).

        In MATLAB, the CSV files open with readtable('swinewash_hydraulics.csv'). If nothing downloads, open the dashboard file directly in your browser instead of a preview.
